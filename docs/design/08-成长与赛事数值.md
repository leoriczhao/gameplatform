# 08 · 成长与赛事数值（v1.0-c 简表）

> 状态：实施简表（随 v1.0-c 实施创建，回答 00-README Q9）
> 用途：成长（XP/等级）与排行（周榜）的数值定义；赛事数值 v1.5 再补。

## 1. XP 事件表（对局结束按 kind 计 XP）

| kind | 触发 | XP |
|---|---|---|
| `pvp_play` | 人 vs 人对局结束（ranked 与 casual 一样，参与即得；任意结束原因：摧毁/时间到/认输/超时） | **+10** |
| `pvp_win` | 上述对局的胜者额外 | **+15** |
| `pve_finish` | PvE 会话打到 done（play API） | **+5** |
| `pve_win` | PvE 会话 done 且胜利（胜者为玩家阵营） | **+5** |

防刷分：每会话只计一次（会话级幂等标记）；模型对战不计；游客不计（无账号）。

## 2. 等级曲线

```
xp_for_level(n) = 50 * n * (n - 1)      # 升到 n 级所需累计 XP（n ≥ 1）
level(xp)      = 满足 50·n·(n-1) ≤ xp 的最大 n
```

| 等级 | 累计 XP |
|---|---|
| L1 | 0 |
| L2 | 100 |
| L3 | 300 |
| L4 | 600 |
| L5 | 1000 |
| L6 | 1500 |
| L7 | 2100 |
| L8 | 2800 |
| L9 | 3600 |
| L10 | 4500 |

（一局 PvP 约 10-25 XP：约 10 局到 L2，50 局到 L5——休闲节奏，不诱导肝。）

## 3. 排行（v1.0-c）

- **总榜**：沿用现有 ELO 积分榜（K=32，起始 1200，`ratings` 表）；
- **周榜**：最近 7 天（自然滑动窗口）`matches` 聚合——按 **胜场数** 降序，
  同胜场按对局数，再按该周 XP；并列同名次；
- ELO 走势：`rating_history` 每次 ELO 结算落一行，前端画最近 50 点的 sparkline。

## 4. 战绩统计（stats/me）口径

- 总对局/胜/负/平/胜率：只统计**已落库的人 vs 人对局**（matches.kind=pvp, finished）；
- 连胜：按对局 id 升序扫描我的对局，当前连胜 = 末尾连续胜场数，另计历史最高；
- 时长：sum(finished_at - created_at)（含超时/认输局）；
- 每游戏分项：对局数/胜场 + 当前 ELO + ELO 走势数组。
