## 1. 背景与目标

现状（渲染 v1，D22）：所有游戏（内置与 UGC 同一管线，D26）都走
`web/src/components/UgBoard.jsx` 的**通用 JSON 棋盘渲染器**——CSS grid + 每格一个
emoji/字符 + 一个背景色。`game.yaml` 的渲染声明只有
`board.{width,height,palette[cell].{glyph,color}}` 与 `units[type].{glyph,color}`
（校验见 `backend/ugc_pack.py::_glyph_item`），包内不允许图片/音频
（`ALLOWED_EXTS` 只有 `.py/.json/.yaml/.txt/.md/.npz/.npy/.bin`）。

天花板因此很硬：没有精灵图、没有朝向、没有单位归属/血条、没有图层、没有动效、
没有 HUD、没有音效。玩家看到的棋盘与"正式游戏"差距明显。

**目标**：在不放弃"平台零游戏代码 / 零代码执行风险"这一核心不变量的前提下，
把棋盘表现力开放到接近正式游戏的水平；对确实需要过程式视觉的游戏，提供
**强隔离的沙箱渲染器**作为最后手段。

**三档能力（本设计一次交付）**：

| 档 | 名称 | 新增信任边界 | 作者能做什么 |
|---|---|---|---|
| **L1** | 声明式渲染 v2 | 无（仍是数据） | 几何/背景/朝向/归属色/血条/图层/矢量图形/动效/HUD |
| **L2** | 资源包（图片+音效） | 无代码，但新增**内容**审核面 | 上传 PNG/WebP 精灵与 OGG/MP3/WAV 音效 |
| **L3** | 沙箱自定义渲染器 | **浏览器内执行不可信 JS**（Worker + OffscreenCanvas，opaque origin） | 提交 `renderer.js`，逐帧自绘棋盘 |

决策日志新增 D28/D29/D30（见 `00-README.md`）。

## 2. 不变量（任何一档都不得破坏）

1. **前端不执行游戏包里的 Python**；L3 的 JS 只在沙箱帧的 Worker 内运行。
2. **服务端是唯一校验边界**：前端把 `meta` 当不可信数据；任何字段缺失/越界/类型错都要能降级渲染而不是崩溃。
3. **作者字符串永不进入 `style`/HTML**：颜色只用 `#rrggbb`，CSS/Canvas 参数由平台从白名单字段构造；
   禁止 `dangerouslySetInnerHTML`、禁止拼接原始 CSS、禁止 `eval`/`new Function`（前端）。
4. **不引入每游戏 React 组件**（D26）：内置游戏与 UGC 走同一套声明/沙箱，平台核心零游戏名硬编码。
5. **确定性**：渲染只读 `state`，不改变游戏逻辑；回放/观战用 `instant` 模式（无补间、无粒子）。
6. **可降级**：任何新特性在旧前端/低端设备/`prefers-reduced-motion` 下必须回退到 v1 的 grid 渲染。

## 3. L1 · 声明式渲染 v2

### 3.1 `board` 扩展

```yaml
board:
  schema: 2                  # 可选，1|2，缺省 2（v1 包省略即按 2 校验，未用新字段则渲染不变）
  renderer: auto             # 可选：auto|dom|canvas（默认 auto：有小棋盘/无障碍需求走 dom，其余 canvas）
  width: 20
  height: 20
  cell:                      # 可选，格子几何
    size: 32                 # 8-64，px 提示（前端按视口再缩放）
    gap: 1                   # 0-8
    radius: 4                # 0-24；shape=circle 时忽略
    shape: square            # square|circle
    border: { color: "#e4e4e7", width: 0 }   # width 0-4
  background:                # 可选，棋盘底
    kind: checker            # plain|checker|grid（默认 plain）
    colors: ["#f8fafc", "#eef2f7"]   # plain 用 colors[0]；checker 用两色；grid 用 colors[0]+line
    line: "#e4e4e7"
  palette:
    empty: { color: "#f1f5f9" }
    body:  { color: "#22c55e", glyph: "●", glyph_color: "#ffffff", scale: 0.85 }
    head:  { sprite: snake_head, orient: { field: direction, angles: [270, 0, 90, 180] } }
    food:  { vector: { path: "M12 2C7 2 3 6 3 11s4 9 9 9 9-4 9-9-4-9-9-9z", color: "#ef4444" },
             anim: { effect: pulse, period: 1200, amount: 0.12 } }
  layers:                    # 可选，最多 4 层叠加（base 层恒为 state.board/render_board）
    - { field: overlay, palette: { fog: { color: "#0f172a", opacity: 0.35 } }, opacity: 0.9 }
  hud:                       # 可选，最多 8 项（见 3.4）
    - { kind: stat, label: 分数, path: score }
    - { kind: miniboard, label: NEXT, path: next_board, width: 4, height: 4, cell: 16,
        palette: { "0": { color: "#f1f5f9" }, "1": { color: "#00b8d9" } } }
  events:                    # 可选，最多 8 条（见 3.5）
    - { name: eat,   effect: { kind: flash, color: "#22c55e", ms: 260 }, sound: eat }
    - { name: death, effect: { kind: shake, ms: 400, amount: 6 } }
```

### 3.2 palette / units 条目字段

`palette[cellId]` 与 `units[type]` 共用同一套条目字段（`_render_item` 校验）：

| 字段 | 类型/范围 | 说明 |
|---|---|---|
| `glyph` | 1-8 字符 | emoji/字符（v1 兼容） |
| `color` | `#rrggbb` | palette：格子背景色（v1 语义）；unit：单位主色（描边/字形/矢量填充） |
| `bg` | `#rrggbb` | 仅 unit：该单位所在格的背景色 |
| `glyph_color` | `#rrggbb` | 字形颜色，缺省按主色/墨色推导 |
| `scale` | 0.2-2 | 字形/精灵/矢量相对格子的缩放 |
| `opacity` | 0-1 | 整体不透明度 |
| `shadow` | bool | 是否加投影（canvas 层） |
| `sprite` | 资源名 | 引用 `assets` 中的图片（L2） |
| `vector` | `{path,color,fill}` | 内联矢量图形（无资源文件，SVG path 语法子集） |
| `orient` | `{field,angles}` | 按 state 字段值在 angles 中取下标做旋转（角度制） |
| `anim` | `{effect,period,amount}` | 常驻动效（见 3.3） |
| `enter` | `{effect,ms}` | 出现/变化时的入场动效 |
| `z` | -10..10 | 同一格的绘制层级（默认 0） |

条目至少要有 `glyph`/`sprite`/`vector` 之一，否则校验拒绝。
`vector.path` 只允许 `[MmLlHhVvCcSsQqTtAaZz0-9eE.,+\- ]`，≤1024 字符，必须以 `M`/`m` 开头；
`fill` 缺省 true（false 时描边）。

**朝向语义**：`angles` 为屏幕坐标系角度（0=右，90=下，逆时针为正的 canvas 约定由前端统一），
按 `state[orient.field]` 的值在数组中的下标旋转；值不在数组里则旋转 0。snake 的
`direction` 0/1/2/3 = 上/下/左/右 → `angles: [270, 90, 180, 0]`（前端按此约定）。

**单位归属与血条**（写在 unit 条目上，读 state 字段）：

```yaml
units:
  worker:
    glyph: "👷"
    owner_colors: ["#2563eb", "#dc2626"]     # 2-4 色，按 state[owner_field] 取
    owner_field: owner                       # 缺省 owner/player/side
    hp: { field: hp, max_field: hp_max, color: "#22c55e" }   # 血条画在格子底部
    label: { field: tag }                    # 1-3 字符小标签画在右上角
    z: 1
```

### 3.3 动效库（白名单，参数服务端夹紧）

- 常驻 `anim.effect`：`pulse`（缩放呼吸）、`glow`（外发光）、`bob`（上下浮动）、
  `spin`（匀速旋转）、`flicker`（透明度闪烁）、`float`（缓慢漂移）。
  `period` 200-5000ms，`amount` 0-1（默认按效果取 0.15）。
- 入场 `enter.effect`：`pop`、`fade`、`flash`、`rise`，`ms` 40-1000。
- 棋盘事件 `events[].effect.kind`：`flash`（整盘闪色）、`shake`（震屏，`amount` 1-12px）、
  `pulse`（整盘缩放）、`dim`（压暗）、`tint`（染色），`ms` 80-2000。

### 3.4 HUD 声明

```yaml
hud:
  - { kind: stat,      label: 分数, path: score, color: "#19191c" }
  - { kind: bar,       label: 能量, path: energy, max: 100, color: "#4f46e5" }
  - { kind: badge,     label: 等级, path: level, color: "#4f46e5" }
  - { kind: text,      label: 状态, path: status }
  - { kind: miniboard, label: NEXT, path: next_board, width: 4, height: 4, cell: 16, palette: {...} }
```

`label` ≤16 字符；`path` 见 3.6；`max` 1-1e9；`cell` 8-32；
`miniboard` 的取值是二维 cell-id 数组（或一维数组 + `width`），行列不足时补 `0`/空。
HUD 渲染在棋盘下方一行（平台统一样式，作者不控制布局）。

### 3.5 状态事件

`state.events`（可选）是**本帧发生的事件名数组**，元素为字符串或
`{name,x?,y?}`。引擎在 `step_state` 里写入，例如 snake 吃到食物时
`events: ["eat"]`。前端消费后不修改 state；事件不在声明里则忽略。
事件效果与 `sound` 同帧触发一次。

### 3.6 路径表达式

`path` 只允许 `^[A-Za-z_][A-Za-z0-9_]*(\.[A-Za-z_][A-Za-z0-9_]*|\.[0-9]+)*$`，
≤64 字符、≤4 段、不含 `__`。前端用纯取值实现，**禁止 eval**。

### 3.7 兼容与默认

- 旧包（无 `schema`/新字段）归一化后 `board.schema=2`、无新增字段 → 渲染与 v1 完全一致。
- 颜色统一小写 `#rrggbb`；数字服务端取整/夹紧，前端再做一次防御性夹紧。
- 校验在 `backend/ugc_pack.py`；作者侧 `gdk-ug/test_runner.py` 做同构的宽松检查（引用完整性 + 路径可解析）。

## 4. L2 · 资源包（图片 + 音效）

### 4.1 声明

```yaml
assets:                                  # 最多 32 个
  snake_head: { file: "assets/head.png", w: 32, h: 32 }
  apple:      { file: "assets/apple.webp" }
sounds:                                  # 最多 16 个
  eat:  { file: "assets/eat.ogg", ms: 400, volume: 0.6 }
  over: { file: "assets/over.mp3", ms: 1200, volume: 0.8 }
```

- 资源名 `^[a-z0-9][a-z0-9_-]{0,23}$`；`file` 必须是包内相对路径（无 `..`、无绝对路径）。
- 图片只接受 **PNG / WebP**：魔数校验（`\x89PNG\r\n\x1a\n` / `RIFF....WEBP`）、
  单文件 ≤256KB、全部资源合计 ≤2MB、单边 ≤512px（从文件头解析尺寸，PNG IHDR / WebP VP8X|VP8 |VP8L）。
- 音效只接受 **OGG / MP3 / WAV**：魔数校验（`OggS` / `ID3` 或 `\xff\xfb` / `RIFF....WAVE`）、
  单文件 ≤512KB、`ms` 10-5000、`volume` 0-1。
- 仍受包级限制：20MB / 200 文件（D23）。
- 引用完整性：palette/unit 的 `sprite` 必须存在于 `assets`，`events[].sound` 必须存在于 `sounds`。

### 4.2 服务与安全

`GET /api/ugc/assets/{slug}/{version}/{path}`

- 仅当该 `version` 是 `active`/`superseded`（公开）或请求者是作者（草稿预览）时可读；
  路径必须**精确命中**该版本 meta 里声明的资源文件（白名单，不做目录遍历）。
- 响应头：`Content-Type` 由服务端魔数嗅探决定（不信任扩展名）、`X-Content-Type-Options: nosniff`、
  `Cache-Control: public, max-age=31536000, immutable`（版本号在 URL 中，版本不可变）、
  `Content-Security-Policy: default-src 'none'`。
- 图片在 `<img>`/`createImageBitmap` 中加载；音频默认**静音**，用户首次点击棋盘区域后解锁，
  棋盘工具条提供静音开关，音量上限 1。

### 4.3 审核

像素/音频无法静态扫描，靠**人工审核 + 配额**：审核清单增加"资源缩略图预览、无侵权素材、
音效无违规内容"；作者工作台展示资源列表与预览。管理后台的 UGC 审核 tab 增加资源预览区。

## 5. L3 · 沙箱自定义渲染器

### 5.1 声明与门禁

```yaml
renderer:
  entry: renderer.js       # 包内 .js，≤128KB，UTF-8
  protocol: 1              # 只支持 1
  fallback: declarative    # declarative（默认）| none
```

- 上传时静态扫描 `renderer.js`：命中 `importScripts(`、`fetch(`、`XMLHttpRequest`、`WebSocket`、
  `document`、`window`、`localStorage`、`eval(`、`new Function` 直接拒绝（审核辅助层，不是边界）。
- **能力门禁**：渲染器默认关闭。官方种子包随发布自动开启；UGC 需管理员在审核通过后
  显式开启（`POST /api/v1/admin/ugc/{gid}/renderer {enabled:true}`），下架/驳回自动关闭。
  公开目录的 `meta.renderer_enabled` 表示当前是否可用；未开启时前端只走声明式渲染。

### 5.2 帧文档（opaque origin + CSP）

`GET /api/ugc/render/{slug}/{version}/frame`（仅 `renderer_enabled` 时可读）

- 平台生成 HTML：内联 `renderer.js` 源码 + 内联资源的 base64（**不发起任何网络请求**）。
- 响应头：
  `Content-Security-Policy: sandbox allow-scripts; default-src 'none'; script-src 'unsafe-inline' blob:; worker-src blob:; img-src data:; connect-src 'none'`
  —— `sandbox allow-scripts`（无 `allow-same-origin`）= **opaque origin**：读不到宿主 DOM/Cookie/Storage，
  `connect-src 'none'` 断网。
- 宿主 `<iframe sandbox="allow-scripts">` 嵌在棋盘位置；iframe 内只做三件事：
  建 Worker（blob，渲染器跑在里面）、转发消息、把 canvas 交出去。

### 5.3 Worker 协议 v1（规范）

帧文档**自包含**：`renderer.js` 源码与资源 base64 由服务端内联进帧 HTML，
帧加载后自建 Worker 并向宿主发 `ready`（不再由宿主传资源）。宿主 → 帧
（postMessage；宿主用 `ev.source === iframe.contentWindow` 校验，帧用
`ev.source === parent` 校验；帧 origin 恒为 `"null"`）：

```js
{ type:"state", state }               // 状态变化时
{ type:"tick", t, dt }                // 宿主每个 rAF 一次（instant 时仅状态变化后一次）
{ type:"resize", width, height, dpr } // CSS 像素尺寸 + 设备像素比
{ type:"dispose" }                    // 卸载
```

帧 → 宿主：

```js
{ type:"ready", hasInput }            // hasInput=false 时帧自行把点击转成 cell
{ type:"error", message }             // 宿主据此回退声明式渲染
{ type:"cell", x, y }                 // 转发给 onCellClick
{ type:"sfx", name }                  // 宿主播放音效（帧自身无音频权限）
{ type:"ack", seq }                   // 看门狗回执（帧内部 tick 序号）
```

渲染器作者 API（`renderer.js` 必须定义 `globalThis.Renderer`）：

```js
globalThis.Renderer = {
  init(api) {},                       // api:{ ctx, width, height, dpr, sprite(name), sfx(name), cell(x,y), sounds }
  frame(state, tMs, dtMs) {},         // 必需；同步绘制，不得阻塞
  resize(width, height, dpr) {},      // 可选
  input(ev) {},                       // 可选：{x,y,cellX,cellY,phase,button}
  dispose() {},                       // 可选
};
```

### 5.4 看门狗与降级

- 帧主线程对每个 `tick` 记时：`ack` 超过 200ms 或连续 3 次未回 → `worker.terminate()`，
  上报 `error`；宿主立即切回声明式渲染，并在本会话内记住该游戏渲染器不可用。
- `error` 累计 3 次或单次初始化失败 → 本会话不再尝试。
- 回放/观战：`t` 由 tick 序号映射，`instant` 模式不插值；渲染器不得依赖真实时钟做游戏判断。

## 6. 前端架构

```
web/src/render/
  paths.js          // getPath(纯取值)、夹紧工具
  schema.js         // normalizeMeta：把服务端 meta 归一化为渲染模型（防御性默认）
  effects.js        // 动效参数 → 时间曲线（纯函数，可单测）
  assets.js         // 资源 URL 构造 + ImageBitmap 预加载缓存
  audio.js          // 音效播放（默认静音、首次手势解锁、并发上限）
  BoardCanvas.jsx   // canvas 2D 渲染器（主渲染路径）
  BoardDom.jsx      // DOM 回退（无障碍/极简/降级）
  Hud.jsx           // 声明式 HUD
  SandboxBoard.jsx  // L3 iframe 宿主 + 看门狗 + 降级
web/src/components/UgBoard.jsx   // 门面：保持既有 props，选择渲染器 + HUD + 静音开关
```

- **props 不变**：`{state, meta, onCellClick?, cellSize?}`，四个调用点
  （`UgPlay`/`UgPvp`/`Watch`/`WatchReplay`）零改动；新增可选
  `instant`（回放）、`interactive`。
- 渲染器选择：`meta.renderer.enabled` → `SandboxBoard`（失败降级）；
  否则 `board.renderer=dom` 或 `prefers-reduced-motion` 或极简棋盘 → `BoardDom`；
  其余 → `BoardCanvas`。
- 资源 URL：`/api/ugc/assets/{slug}/{meta.version}/{file}`；预加载失败只降级该元素。
- 纯逻辑（paths/schema/effects）用 `web/tests/*.test.js`（node --test）覆盖；
  canvas 组件不引入 jsdom/canvas 依赖。

## 8. 验收标准

1. `pytest -q` 全绿（新增：v2 schema 正反例、资源魔数/尺寸/引用、门禁、帧 HTML 生成）。
2. `cd web && npm test && npm run build` 全绿。
3. 三个官方包用 v2 渲染：snake 蛇头随方向旋转 + 食物呼吸 + 分数 HUD；tetris 方块精灵 + NEXT 小棋盘；
   microrts 单位归属描边 + 血条。
4. 旧 v1 包（无新字段）渲染与升级前逐像素级一致（结构一致即可）。
5. L3：官方包或测试包声明 `renderer` 后，管理员开启才加载；断开 `renderer.js`（或故意死循环）
   时前端 1 秒内回退声明式并提示一次。
6. `/api/ugc/assets/...` 只吐出声明过的文件；改扩展名/伪造魔数/超限/目录遍历全部 4xx。
7. 文档：本文件 + `00-README.md` 决策日志 + `09` 指南 + `README.md` 同步。

## 9. 非目标（本版不做）

- 任意前端框架/React 组件上传；SVG 文件（矢量用内联 `vector.path` 表达，避免 XML 消毒难题）。
- 每游戏独立 HTML 页面/路由、自定义布局（HUD 位置由平台统一样式）。
- 资源转码/压缩服务（作者自行压缩；服务端只做校验与嗅探）。
- 网络请求、持久化、跨局状态：L3 渲染器纯函数式绘制，不得联网/写存储。
