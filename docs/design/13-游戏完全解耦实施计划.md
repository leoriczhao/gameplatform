## 0. 前置与总原则

- **一条管线**：任何游戏（官方种子/用户上传）都只走「校验→扫描→解包→冒烟→注册」；
- **零游戏名**：平台运行时（backend 非 games 部分 + web）不允许出现任何具体游戏的
  控制流分支；grep 检查进验收；
- **破坏性改动允许**：允许删除 backend/games/、专属前端页面；slug 与 HTTP 路径不变，
  历史数据保留；
- 每个阶段结束：pytest 全绿 + rsync 上线 + 生产验收，再进下一阶段；
- 旧代码与包规范 v1 的兼容由 12 §3.2 保证：用户已上传的 UGC 游戏包不用改。
