## 1. 产品定位：我们做的到底是什么

一句话：**一个"游戏 + 训练 + 模型对战"三位一体的多游戏 RL 对战平台。**

- 不是"几个小游戏网页"：游戏库是平台内容，账号/社交/成长/赛事/运营是平台骨骼；
- 不是 Steam/BGA 的翻版：桌面游戏平台卖"内容与社交"，我们的核心差异是
  **同一套引擎同时支撑三件事**——网页玩（PvE/PvP）、远程环境采样与客户端训练（env API + SDK）、
  模型对抗（托管/排位/约战）。训练与游玩共用 `EnvAdapter`（D3），这是别的平台没有的闭环；
- 对标参照（功能来源，非照搬）：
  - **BGA**：一账号多游戏、每游戏独立 ELO、Arena 赛季、锦标赛、大厅/房间、好友、聊天、声誉(karma)（[IGN 功能导览](https://sea.ign.com/tabletop-2/230927/guide/everything-you-need-to-know-about-board-game-arena)、[BGA 机制综述](https://en.namu.wiki/w/%EB%B3%B4%EB%93%9C%EA%B2%8C%EC%9E%84%20%EC%95%84%EB%A0%88%EB%82%98)）
  - **Lichess**：快速匹配、casual/rated、积分放宽撮合、锦标赛、战队、学习内容（[匹配架构](https://deepwiki.com/lichess-org/lila/3.1-lobby-and-matchmaking)）
  - **BattleSnake**：bot 即选手的开发者平台、Ladder/Arena/Battlegrounds 三层对战、观战回放（[Competitive Play](https://docs.battlesnake.com/guides/competitive-play)）
  - **Steamworks**：平台功能清单范式——成就/统计/排行榜/社区/创意工坊/反作弊/通知/封禁（[Steamworks 功能文档](https://partner.steamgames.com/doc/features?l=schinese)）
  - **QQ 游戏大厅/棋牌**：房间制、等级成长、道具经济、断线重连（[房卡模式](https://forum.cocos.org/t/topic/176889)、[ELO 分房+重连](https://datasea.cn/go0211480852.html)）
  - **Halite**：模型排位与 TrueSkill 积分（[积分报告](https://github.com/Janzert/halite_ranking/blob/master/rating-report.md)）

## 2. 用户角色（Personas）

| 角色 | 描述 | 核心诉求 |
|---|---|---|
| P1 休闲玩家 | 游客/注册，想随手玩两局 | 打开即玩、打 AI、上榜、围观 |
| P2 竞技玩家 | 注册，冲分上分 | 快速匹配、公平积分、赛季榜、锦标赛 |
| P3 模型作者（开发者） | 训练模型上传对抗 | 训练→导出→上传→评估→排位→分享全链路 + 模型主页 |
| P4 观战者 | 不玩只看的用户 | 围观高手局、回放、分享对局 |
| P5 运营/管理员 | 平台维护者 | 用户/模型管理、仲裁、公告、数据看板 |

**第一天旅程（验收用例）**：注册 → 大厅选游戏 → 玩一局 PvE 上榜 → 快速匹配打一盘
ranked 加 ELO → 在房间聊天 → 打完围观别人的局 → 看回放 → 分享战绩链接给朋友 →
朋友凭链接进来 → 成为好友 → 第二天看到赛季榜变化。

> **旁注**：上列为 v1.0 历史验收路径（玩法优先），**非现行大厅主 CTA**。现行主旅程（训练闭环）见 [`docs/pm/01`](../pm/01-定位与用户.md)。

### 模块依赖（实施顺序的依据）

```
B(账号) ──▶ C(游玩/匹配/观战回放) ──▶ G(聊天/分享) ──▶ D(成长) ──▶ E(赛季) ──▶ H(赛事)
A(游戏库/GDK) ─┘               └──▶ F(模型生态：排位池/广场) ──▶ H
K(风控) 贯穿始终；J(运营后台) 随各模块数据积累逐步增强；L(基建) 随阶段补
```

## 4. 完整用户用例（User Stories，按角色）

**休闲玩家**
- U-C1 我是游客，打开就能玩 PvE，不需要注册（已有）
- U-C2 我玩完一局能把自己的成绩提交上榜，看到排名（已有）
- U-C3 我在大厅能看到"正在等人的公开房间"，点进去就能和真人打
- U-C4 我能在对局房间里和对手聊天
- U-C5 我能围观任何公开对局，结束后看回放

**竞技玩家**
- U-R1 我点"快速匹配"，系统按 ELO 给我配旗鼓相当的对手
- U-R2 练手局(casual)不掉分，排位局(ranked)才计 ELO
- U-R3 我打完能"再来一局"，自动换先后手
- U-R4 我能看到总榜/周榜/赛季榜和自己的历史走势
- U-R5 我断线/刷新后能从"我的对局"横幅一键回到对局
- U-R6 我能报名参加锦标赛，看到对阵图，输了也能围观决赛

**模型作者**
- U-M1 我按教程训练模型 → SDK 导出 ONNX → 上传即通过契约校验（已有）
- U-M2 我能评估模型，把模型挂进排位池自动打，上模型分榜
- U-M3 我能把模型设为"公开"，在模型广场被别人发现、点赞、挑战
- U-M4 模型主页展示我的胜率曲线与历史对局
- U-M5 我能创建/加入模型锦标赛（v2）

**观战者**
- U-S1 我能通过分享链接直接打开一局对局的实时观战或回放
- U-S2 我能浏览"精彩对局"列表，按游戏/段位筛选

**运营**
- U-O1 我能发全站公告（大厅顶部横幅）
- U-O2 我能封禁用户、下架恶意/违规模型、仲裁争议对局
- U-O3 我能看数据看板：日活、对局数、新注册、模型上传趋势

## 5. 平台架构分层（升级 01 的全景）

```
┌─────────────────────────── 客户端层 ───────────────────────────┐
│  Web SPA（大厅/游戏页/模型/观战/资料/后台）· 移动端响应式            │
│  Python SDK（RemoteVecEnv / export_onnx / PlatformClient /      │
│              SessionClient）· 外部 bot（HTTP 协议）              │
├─────────────────────────── API 层 ─────────────────────────────┤
│  /api/openenv/{game}/* 训练面（官方 OpenEnv；旧 /env 已删除）      │
│  /api/{game}/ai·scores 游玩辅助                                  │
│  /api/v1/*：auth · play(会话/房间/匹配/观战) · models · matches   │
│  /api/v1/social·stats·events·admin（新增模块）                    │
├─────────────────────────── 服务层 ─────────────────────────────┤
│  会话服务(内存) · 匹配队列 · 对战 worker 池 · 聊天 · 通知 · 统计    │
│  成长/成就引擎 · 赛季调度 · 赛事编排 · 风控(限流/校验/举报)         │
├─────────────────────────── 引擎层（核心资产）───────────────────┤
│  游戏注册表 registry + EnvAdapter 统一引擎：info/new_state/       │
│  step_state/validate/obs/ai_action —— 玩/训/战三面共用（D3）      │
├─────────────────────────── 数据层 ─────────────────────────────┤
│  SQLite：users/models/matches/ratings/scores                    │
│  新增表：friends, chat_messages, notifications, xp_events,       │
│          achievements, seasons, tournaments, reports, model_stats│
└────────────────────────────────────────────────────────────────┘
```

## 6. 路线图（v1.0 可运行 MVP → v1.5 → v2.0）

### v1.0「平台可运行」——P0 ✅ 已交付（2026-08）

> ✅ 批次顺序已确认（用户拍板，Q8）：**a 对战完备 → b 身份与社交最小 →
> c 成长与排行 → d 运营最小 → e 基建**；房间聊天放在 b 批次（不进 a）。
> 任务级拆解与验收见 [07-v1.0实施计划与交接](./07-v1.0实施计划与交接.md)。
> **交付状态：五批次已全部实施、测试（136）全绿、逐批上线并通过生产验收；
> 下一里程碑为 v1.5「生态初成」。**

> 验收标准一句话：**两个陌生人从注册到匹配对局到聊天、观战、回放、上分、
> 分享，全程不需要离开平台，也不需要管理员手工介入。**

| 批次 | 内容 | 依据 |
|---|---|---|
| v1.0-a 对战完备 | 房间系统 + 快速匹配（06 M1-M2）、断线重连 + rematch（06 M3）、观战 + 回放器 + 对局分享链接（06 M4） | 06 |
| v1.0-b 身份与社交最小 | 个人资料页（昵称/头像/签名）、好友（加/删/在线）、房间内聊天 | B/G |
| v1.0-c 成长与排行 | XP/等级、对局统计（个人主页战绩墙）、总榜/周榜、ELO 走势 | D/E |
| v1.0-d 运营最小 | 公告系统、管理后台（用户封禁、模型下架、数据看板）、举报 | J/K |
| v1.0-e 基建 | 站内通知、移动端响应式、SQLite 备份脚本、GDK 接入文档 | L/A |

### v1.5「生态初成」——P1

模型广场与模型主页（F）、模型排位池（06 M5）、成就徽章（D）、
锦标赛（H）、赛季榜+赛季奖励（E）、karma 声誉（对标 BGA，防挂机/违规）、
**用户上传游戏（UGC 游戏库，新立项，见 10-用户上传游戏设计 + 11-实施计划）**。

### v2.0「平台化」——P2

赛季联赛 + 限时竞技场（BattleSnake Arena 式，H）、大厅聊天/私信（G）、
国际化、TrueSkill 积分（D9 演进）、多副本 + Redis（D12 演进）、
管理后台增强、道具/皮肤经济（可选，视运营需要）。
