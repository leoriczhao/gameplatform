## 1. 目标（v1.0 MVP）

把现有"有对战功能的游戏网站"升级为**可运行的完整游戏平台**。

**验收标准（一句话）**：两个陌生人从注册到匹配对局、聊天、观战、回放、上分、
分享，全程不需要离开平台，也不需要管理员手工介入。

**已确认的决策**（用户拍板，2026-xx）：
- 批次顺序：**a 对战完备 → b 身份与社交最小 → c 成长与排行 → d 运营最小 → e 基建**
- 房间聊天放在 **b 批次**（不进 a）
- 平台愿景、模块全景（A-L）见 00 蓝图；房间/匹配机制细节见 06

## 5. 新增数据表规划（✅ 已全部建成；users 另补 avatar/signature/xp 列，含 ALTER 迁移守卫）

```sql
-- b 社交
CREATE TABLE IF NOT EXISTS friends (
  user_id INTEGER NOT NULL, friend_id INTEGER NOT NULL, created_at REAL NOT NULL,
  PRIMARY KEY (user_id, friend_id));
CREATE TABLE IF NOT EXISTS chat_messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT, room_id TEXT NOT NULL,
  user_id INTEGER NOT NULL, nickname TEXT, text TEXT NOT NULL,
  created_at REAL NOT NULL);
CREATE TABLE IF NOT EXISTS notifications (
  id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER NOT NULL,
  kind TEXT NOT NULL, body TEXT NOT NULL, link TEXT, read INTEGER DEFAULT 0,
  created_at REAL NOT NULL);
-- c 成长/排行（周榜可直接按时间窗聚合 matches/ratings 快照）
CREATE TABLE IF NOT EXISTS xp_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER NOT NULL,
  game TEXT, kind TEXT NOT NULL, xp INTEGER NOT NULL, created_at REAL NOT NULL);
CREATE TABLE IF NOT EXISTS rating_history (   -- ELO 走势
  game TEXT NOT NULL, user_id INTEGER NOT NULL, rating REAL NOT NULL,
  created_at REAL NOT NULL);
-- d 运营
CREATE TABLE IF NOT EXISTS announcements (
  id INTEGER PRIMARY KEY AUTOINCREMENT, body TEXT NOT NULL,
  active INTEGER DEFAULT 1, created_at REAL NOT NULL);
CREATE TABLE IF NOT EXISTS reports (
  id INTEGER PRIMARY KEY AUTOINCREMENT, reporter_id INTEGER NOT NULL,
  target_type TEXT NOT NULL, target_id INTEGER NOT NULL, reason TEXT,
  status TEXT DEFAULT 'open', created_at REAL NOT NULL);
```

`users` 表补列：`nickname`（已有）、`avatar`、`signature`、`xp`、`role`（user|admin）。

   写 JSX 时格外小心语法；必要时先在服务器上 `docker compose build web` 单独验证。
3. 所有新端点同步更新：`frontend/api.html`、SDK `client.py`、`00/06` 相关文档。
4. 会话仍是内存态：房间列表/匹配队列也内存态（D12），实现里写清楚重启即失效，UI 不做持久化承诺。
5. 测试沿用现有模式：TestClient + 临时 SCORES_DB/MODELS_DIR + 直接 monkeypatch 模块常量
   （如 `sessions.PVP_TIMEOUT`，注意 env 在 import 时固化、其他测试模块可能已 import）。
