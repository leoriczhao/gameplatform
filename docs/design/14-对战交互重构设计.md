# 14 · 对战交互重构设计（D27）

> 状态：**已交付（2026-08，评审通过 → 已上线验收）** · 用户拍板：撤掉独立对战中心，对战完全按游戏归属
> 关联：D26（游戏解耦）/ 00（蓝图）/ 03（PvP 流程）/ 13（实施计划）

## 1. 问题

1. 「对战中心 /arena」用**单一下拉框**选游戏，游戏一多不可用；
2. 我上一轮按「PvP 或 有模型契约」把 **PvE 游戏（贪吃蛇/俄罗斯方块）也放进了对战中心**——概念错误；
3. 整体信息架构混乱：「对战」与「游戏」被拆成两个平行模块，用户心智负担大。

## 2. 决策（用户拍板 D27）

- **撤销独立「对战中心」页面与导航入口**；
- **对战跟着游戏走**：大厅卡片直接进该游戏的 PvP 对战页；
- **模型 vs 模型（AI 挑战）** 从对战中心移除，迁往「模型托管」页；
- 先评审本设计（文档 + 可点击线框原型）再实现。

## 3. 新信息架构（IA）

```
顶部导航：大厅 | 模型托管 | 上传游戏 | 好友 | 通知 | 资料 | API 文档
            （← 去掉「对战中心」）

/, 大厅（游戏库）
  ├─ 公告横幅
  ├─ Hero：品牌 + 主 CTA（进游戏 / 模型托管 / 上传 / 登录）
  ├─ 游戏卡片网格
  │    每卡：图标·名称 + 徽标（⚔️可对战 / 🧠内置AI / 作者）
  │    [进入游戏]  [对战⚔️ → /games/{slug}/pvp]（仅 PvP 游戏）  [环境 info]
  └─ 底部：后端在线状态 / API 文档 / Swagger

/games/{slug} 游戏单机页（现状扩展）
  ├─ 游玩区：棋盘/动作输入/内置 AI 演示/提交分数
  ├─ 「去对战」按钮（仅 PvP 游戏）→ /games/{slug}/pvp
  └─ 单机排行榜

/games/{slug}/pvp 对战页（合并 Arena 的 PvP 功能，当前页增强）
  ├─ Tab「找对手」：公开房间列表（5s 轮询）+ 快速匹配 + 邀请码开房
  ├─ Tab「对局」：已进入的对局（棋盘/指令构建器/聊天/认输/重赛）
  ├─ Tab「排行榜」：该游戏 ELO 总榜 + 周榜
  └─ 需要登录（游客见登录引导）

/models 模型托管（新增「模型挑战」区）
  ├─ 我的模型 + 上传 + 单个模型评估
  ├─ 模型 vs 模型 挑战：游戏磁贴条（仅契约游戏）→ 我的模型 vs 内置AI策略/他人模型ID
  └─ 挑战记录：发起的对局列表（状态/结果/回放/分享）

/profile 资料页（新增「我的对局」区块）
  ├─ 昵称/头像/签名 + ELO 走势
  └─ 我的对局：PvP 对局 + 模型挑战记录（状态/结果/回放/分享）

/watch* 观战/回放（保持按 id）
  └─ 从对局记录/分享链接进入
```

## 4. 页面规格

### 4.1 大厅（改动小）
- 复用现有卡片网格；
- PvP 游戏卡片增加**「对战 ⚔️」**次按钮，直达 `/games/{slug}/pvp`；
- 徽标规则：`pvp_enabled` → ⚔️ PvP；`has_ai` → 🧠 内置 AI；UGC 显示作者；
- （增强项，P1 可选）PvP 卡片底部显示「N 个公开房间」，5s 轮询，点击直达该游戏对战页——需要批量房间计数端点，暂不承诺。

### 4.2 游戏单机页 /games/{slug}（UgPlay 小改）
- PvP 游戏顶部操作区加 **「去对战 ⚔️」** 按钮 → `/games/{slug}/pvp`；
- 其余（游玩/AI 演示/单机榜）不动。

### 4.3 对战页 /games/{slug}/pvp（UgPvp 增强，核心改动）
- 页面改为三 Tab：
  1. **找对手**：公开房间列表（房主/模式/邀请码/时间/加入）、快速匹配（ranked/casual + 排队动画）、邀请码（创建私有/加入）；
  2. **对局**（当前已有）：邀请码/对局进行/指令构建器/聊天/认输/重赛——进入对局后自动切到此 Tab；
  3. **排行榜**：该游戏 ELO 总榜 + 周榜（从 Arena 迁移，无游戏选择器）。
- 游戏上下文：页头显示游戏名 + 「回单机页」链接；
- 房间列表 5s 轮询（与现 Arena 一致）。

### 4.4 模型托管 /models（新增「模型挑战」区）
- 新增区块：**游戏选择**（GameStrip 磁贴条，仅 contract 游戏）→ 我的模型下拉 + 对手（内置 AI 策略 / 他人模型 ID）→ 发起；**挑战记录**列表（对应现状 Arena 的模型对战 + 我的对局中模型部分）。
- 复用现有 /api/v1/matches 接口，无后端改动。

### 4.5 资料页 /profile（新增「我的对局」区块）
- 复用 Arena 的「我的对局」表格（PvP + 模型挑战，状态/结果/回放/分享），按时间倒序，分页。
- 移除了 Arena 后此功能必须有家。

## 5. 迁移清单（实现阶段）

| 现状 | 去向 |
|---|---|
| /arena 页面 + 导航入口 | **删除**；AppShell 移除导航项；App.jsx 移除路由 |
| Arena 的公开房间/快速匹配/邀请 | → /games/{slug}/pvp 的「找对手」Tab |
| Arena 的 ELO 总榜/周榜 | → /games/{slug}/pvp 的「排行榜」Tab |
| Arena 的模型 vs 模型 | → /models 的「模型挑战」区 |
| Arena 的我的对局 | → /profile 的「我的对局」区块 |
| GameStrip 组件 | 保留复用（/models 挑战区的游戏选择） |
| 大厅卡片「对战」 | 新增（pvp_enabled 才显示） |

## 6. 验收标准（评审通过后）

1. 顶部导航无「对战中心」，/arena 返回首页或 404；
2. 大厅 PvP 卡片有「对战」，点击直达该游戏对战页；
3. 对战页三 Tab（找对手/对局/排行榜）功能与现 Arena 等价（房间轮询、匹配、邀请、ELO 榜）；
4. PvE 游戏（贪吃蛇/俄罗斯方块/猜数字）在任何对战入口都不出现；
5. 模型挑战在 /models 可用（游戏磁贴切换、发起、记录、回放）；
6. 我的对局在 /profile 可见；
7. 前端 build 通过、全量 pytest 绿、生产验收后交付。

1. 「找对手/快速匹配/排行榜」放各游戏对战页 ✅；
2. **模型挑战同时放游戏页**（契约游戏在单机页可发起）与模型托管页 ✅；
3. 我的对局 → 独立**「战绩」页面**（不塞资料页）✅；
4. 大厅实时房间数（5s 轮询，点击直达）与对战页房间搜索**本轮实现** ✅；
5. /arena **破坏性移除**，无跳转、无别名 ✅；
6. 撤销后 /arena 未知路由 → 统一回落到大厅（SPA 兜底）。
