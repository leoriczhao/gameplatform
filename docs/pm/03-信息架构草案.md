## 1. 现网 IA（代码现状）

### 1.1 顶栏（`AppShell.jsx`）

- Logo「Stream」→ `/`（大厅）  
- 导航顺序：**战绩** `/records` → **模型托管** `/models` → **上传游戏** `/ugc` → **好友** `/friends` → **资料** `/profile`  
- 外链：**API 文档** `/api.html`  
- 通知铃铛 → 下拉 + `/notifications`  
- 登录 / 用户菜单；管理员可进 `/admin`（以页面权限为准）

### 1.2 大厅 `/`（`Lobby.jsx`）

- 公告横幅（`GET /api/v1/announcements`）  
- **Hero**：品牌 Stream + 文案（OpenEnv + 可玩 + PvP）+ CTA 顺序：**战绩**（主按钮）→ 模型托管 → 上传游戏 → 登录  
- 游戏卡片：进入游戏 / 对战（若 `pvp_enabled`）/ OpenEnv Schema 链接；公开房间数轮询  
- 底栏：后端在线提示 · API 文档 · Swagger  

→ 现网心智偏「游戏大厅 + 战绩」，训练闭环未占主 CTA。

### 1.3 游戏内路径

| 路径 | 页面 | 职责摘要 |
|---|---|---|
| `/games/{slug}` | UgPlay | 单机/会话 PvE、AI/模型演示、分数；可去 PvP |
| `/games/{slug}/pvp` | UgPvp | Tab：找对手 / 对局 / 排行榜 |
| `/games/ugc/{slug}[/pvp]` | 同上 | 历史别名路由仍挂载 |

### 1.4 平台级路径

| 路径 | 说明 |
|---|---|
| `/models` | 上传/列表/评估/模型挑战 |
| `/records` | 战绩 |
| `/ugc` | 上传游戏包 |
| `/friends` · `/profile` · `/notifications` · `/admin` | 社交/资料/通知/后台 |
| `/watch/...` | 观战与回放 |
| `/arena` | **不存在**（`NotFound` 明确提示已移除） |

## 2. 目标 IA（已确认决策）

### 2.1 顶栏

**优先露出**：**模型托管**、**API 文档**（可仍为外链或升级为站内文档页，视觉方案由 Game UI 定）。  

建议顺序草案（供视觉，非已实现）：

`大厅` · **模型托管** · **API 文档** · 上传游戏 · 战绩 · 好友 · 资料 · 通知 · 登录  

（「战绩」保留可达，但不再抢主视觉优先级。）

### 2.2 大厅 Hero

- 一句话：**RL 实验室**——OpenEnv/SDK → ONNX → 托管 → 对抗  
- **主 CTA**：模型托管 / API（或「开始训练」指向文档+Schema）  
- 次 CTA：上传游戏、登录；网页玩/对战不作为主按钮  

### 2.3 游戏卡片

- **强调**：环境身份（OpenEnv URL/Schema）、契约/是否支持模型、版本或官方标记  
- **进入游戏 / 对战**：保留，但对战为**次要**按钮或次级文案  
- 房间数可保留为活跃度提示，不主导叙事  

### 2.4 对战归属（不变）

- 对战仍在 `/games/{slug}/pvp`  
- **不恢复** `/arena` 或顶栏「对战中心」  
- 模型 vs 模型留在 `/models`（及游戏页内挑战区），不迁回独立对战中心  

### 2.5 目标站点地图（逻辑）

```
/                      大厅：Hero(训练闭环) + 环境卡片(契约优先)
/models                主路径：托管 · 评估 · 模型挑战
/api.html · /docs      主路径：契约与 OpenAPI（外链可接受）
/ugc                   扩供给：上传游戏包
/games/{slug}          验证：网页玩
/games/{slug}/pvp      验证：人机/人对人（次要入口）
/records               复盘辅助
/watch/*               观战回放
/friends /profile /notifications /admin
```

## 3. 硬约束（实现与设计都不得踩）

| 编号 | 约束 | 说明 |
|---|---|---|
| **D27** | 无独立对战中心 | `/arena` 破坏性移除；对战按游戏 slug 归属；见设计 14 |
| **D26** | 平台零游戏名硬编码 | 官方包与 UGC 同沙箱管线；通用 UgPlay/UgPvp |
| **OpenEnv 唯一环境入口** | 训练面只用 `/api/openenv/{game}` | 旧批处理 env API 已删，无兼容 |
| **D12** | 会话/房间/匹配队列内存态 | 产品文案勿暗示跨重启续局（玩法会话） |
| **D14** | 聊天/通知轮询落库 | v1 不强制上 WS 大厅聊天 |
| **路由语义** | 重大改路由先征得用户同意 | Frontend/Backend 协作；PM 改 IA 文案优先于改 path |

> Decision Log 里若出现与设计 14 冲突的旧 D27 表述，**以设计 14 + 现网路由为准**。

## 4. 对 Game UI 的交接要点

1. 全新视觉，不是现壳换皮；但 **URL 语义尽量保持**（尤其 `/games/{slug}/pvp`、`/models`）。  
2. 主路径视觉权重：模型托管 + API + 环境契约 ≫ 对战按钮。  
3. 对照 `web/DESIGN.md` 做落地规范反馈；本文件不改 DESIGN 正文。
