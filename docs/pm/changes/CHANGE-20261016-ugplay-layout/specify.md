# CHANGE-20261016-ugplay-layout specify

- 要解决的问题：`/games/:slug`（UgPlay）游客态布局不合理——登录 CTA 重复、文案打架、底部「模型挑战」空壳占版；且布局被棋盘格数撑高（microrts 16×16 vs snake 等）带着侧栏/整页走。
- 非目标：不改 OpenEnv 契约；不改路由硬约束（无 `/arena`）；不做全站改版；模型挑战能力本身不删，只迁出本页主视线。
- 用户触点：验证支线「网页玩」；P3 主路径仍在大厅/模型/API。
- IA 定稿（待 UXUI 出稿确认）:
  1. 左：棋盘预览 + **单一**登录门（去掉重复条）
  2. 右：排行榜为主；去掉侧栏第二块登录卡（或合并进唯一门）
  3. 「模型挑战」不贴本页下方空白 → 引导至 `/models`（链或按钮即可）
  4. UGC/上传不抢主 CTA；「去对抗」保留为游戏内 PvP 入口（验证支线）
  5. 文案统一：游客可预览；登录后可操作/上榜（与真实能力对齐，别左右打架）
- 布局硬约束（棋盘尺寸无关）:
  - 棋盘区：**视口比例上限 + 内部缩放**（按格数适配），不写死双栏比例
  - 侧栏：**独立滚动**，不被棋盘撑高拖走
  - 小棋盘不留大片白；大棋盘不挤掉侧栏关键信息
- 成功指标：microrts + snake（至少）游客页无双登录卡、无底部空挑战壳；不同棋盘尺寸侧栏仍可读；UXUI handoff 后 Dev 改 `UgPlay`。
- 风险：登录门文案须与实际权限一致（游客能否上榜以现网为准）。
