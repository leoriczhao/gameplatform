## 2. 关键页面职责

### AppShell（`components/AppShell.jsx`）

- 全局顶栏、主导航、API 文档外链、通知铃铛、用户菜单、`<Outlet />`  
- **IA 改版首要落点之一**（导航顺序与主次）

### Lobby

- 拉 `/api/games`、公告、PvP 房间数；Hero + 卡片网格  
- **IA 改版首要落点之二**（Hero 文案/CTA、卡片强调契约）

### UgPlay

- 通用游戏单机：棋盘（UgBoard）、动作、内置 AI、会话 PvE、游客 OpenEnv 预览、模型挑战入口、去 PvP  
- 依赖：`openenv.js`、`/api/v1/{game}/play/sessions*`、可选 scores/ai

### UgPvp

- 三 Tab：找对手（公开房/匹配/邀请码）· 对局（棋盘/聊天/认输/重赛）· 排行榜  
- 依赖：play rooms、matchmaking、sessions、chat、ratings/leaderboards

### Models

- ONNX 上传与列表、评估、模型挑战（`ModelChallenge`）、挑战记录导向 matches/回放

### UgUpload

- 用户上传游戏包草稿、版本与提交审核入口（对接 ugc API）

### Records / Profile / Friends / Notifications / Admin / Watch*

- 战绩聚合、资料与成长展示、好友、通知全页、运营与 UGC 审核、观战回放  
- Admin 体量大，含用户/模型/对局/举报/公告/UGC 等区块
